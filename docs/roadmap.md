# Roadmap / Yol haritası

Current local candidate: browser-based audit on `127.0.0.1`, grouped findings, real scan charts, EN/TR settings, local reports, protected crawler and developer CLI.

Before public beta update: user review, clean install and packaged Windows launch verification, English screenshots from that exact build, final release notes and approval.

Possible later work, based on feedback: saved audit history, snapshot comparisons in the web interface, and a signed one-click Windows package. No dates or commitments are implied.
